## Description

This repository contains the Python projects and data analysis work I completed during my ShadowFox Python Development Internship.

The internship tasks helped me practice Python fundamentals, problem-solving, web scraping, game development, data analysis, and data visualization. I completed five tasks from the Beginner level, both Intermediate-level tasks, and one Advanced-level task based on IPL batting data.
